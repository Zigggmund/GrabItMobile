<h3>Описание</h3>
GrabIt - это мобильное приложение для краткосрочной аренды, позволяющее арендаторам искать объекты на карте, бронировать доступные слоты и общаться в чате, а арендодателям — управлять объявлениями, календарем доступности и входящими заявками.
<h3>Overview</h3>
GrabIt is a short-term rental mobile application that allows renters to find properties on a map, book available slots, and chat in real-time, while landlords can manage listings, availability calendars, and incoming booking requests.


## Get started
1. Install dependencies
   ```bash
   npm install
   ```
2. Testing with android device
   ```bash
   npx expo run:android
   ```

3. Testing fake api
   ```bash
   npx json-server --watch db.json --port 3001 --host 0.0.0.0
   ```
